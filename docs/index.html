Logic bug or just noise?

You edit a quantum circuit and its output changes. Did you break the logic, or is the hardware simply noisier now? A normal test cannot tell, because every quantum measurement is random and every real device is noisy. This page shows how to separate the two by looking at the same circuit twice.

    This page is a small JavaScript re-implementation of qdebug for circuits of up
      to three qubits, with a depolarizing noise model. The real tool is a Python package that does the same thing
      for Qiskit circuits on IonQ's cloud simulators and noise models, and blames the exact edit that broke the logic.
      The engine behind this page is tested against the Python package and against Qiskit Aer.
